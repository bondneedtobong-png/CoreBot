# Бэклог и замечания по коду

Актуально на апрель 2026. Сжатый список того, что стоит доработать (часть пунктов перенесена из старых `ROADMAP.md` / `TASKS_FIX.md`).

## Исправлено в ходе последних правок

- **Конфликт `cancel`:** раздельные callback — `cancel_accounts`, `cancel_mailing`, `cancel_proxy`; для старых сообщений — fallback `cancel` → главное меню (`bot/main.py`).
- **Двойной `callback.answer()`** в `account_view` при «аккаунт не найден» — убран лишний ответ.
- **Удаление аккаунта:** при отсутствии записи в БД больше не показывается сообщение «удалён»; путь к сессии через `SESSIONS_DIR` из конфига.
- **Коллизия callback `account_delete_*` и `account_delete_confirm_*`:** финальное удаление по шаблону `^account_delete_\d+$` (только числовой id).
- **`proxy_assign`:** ответ на callback после успешной смены прокси (раньше на успехе ответ мог не отправляться).
- **Рефакторинг:** `bot/handlers/accounts/` — пакет модулей вместо одного огромного файла.
- **Дублирование DB-сессии:** единый контекст `database.session.session_scope()` (обёртка над `db.async_session_maker()` + rollback при исключении); хендлеры и `workers/manager.py` переведены с пары `db.engine.begin()` + `sessionmaker(conn)`.

## Высокий приоритет

1. **Рассылка:** сейчас по сути используется один аккаунт за итерацию; нет ротации/балансировки — см. `WorkerManager.start_mailing()`.
2. **`typing_enabled` захардкожен** в `start_mailing()` (`workers/manager.py`, TODO в коде) — вынести в модель рассылки.
3. **Остановка рассылки из UI** — убедиться, что есть устойчивая остановка и сброс состояния.

## Средний приоритет

- Graceful shutdown: корректная остановка рассылки и отключение воркеров по Ctrl+C.
- Пагинация списков аккаунтов / клиентов / рассылок.
- Тесты (pytest) для репозиториев и критичных хендлеров.
- Дублирование логики API credentials (если есть в нескольких местах) — централизовать.

## Низкий приоритет / идеи

- Кэш или фоновое обновление `photo_count` на карточке после операций с аватарками.
- Единый стиль `parse_mode=ParseMode.HTML` во всех ответах бота.
