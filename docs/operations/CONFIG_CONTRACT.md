# Контракт конфигурации CoreBot

Источник истины по именам — `.env.example` в корне репозитория.
Файл `.env` инстанса (`/opt/corebot/app/.env`, права `600`,
владелец `corebot:corebot`) обязан содержать все обязательные переменные.
Владелец параметра: **оператор** (админ деплоя, заполняет при установке)
или **пользователь** (владелец инстанса, предоставляет значение оператору).
«Секретно = да» означает: значение не попадает в Git, логи, отчёты и карточки
инстанса в открытом виде; в карточке хранится только факт наличия.

Fail-fast: установка останавливается с ошибкой при пустых `API_ID`,
`API_HASH`, `BOT_TOKEN`, `OWNER_ID`, при `CP_JWT_SECRET` или
`CP_BOOTSTRAP_ADMIN_PASSWORD` равных `change-me-please`/`change-me`/`admin123`,
а также при пустом `CP_JWT_SECRET`.

## Telegram API и Control Bot

| Переменная | Обяз./опц. | Секретно | Допустимые значения | Владелец |
|------------|-----------|----------|---------------------|----------|
| `API_ID` | обязательная | да | целое число, выданное на my.telegram.org; общий app на команду | оператор (общий шаблон) |
| `API_HASH` | обязательная | да | 32 hex-символа с my.telegram.org; общий app на команду | оператор (общий шаблон) |
| `BOT_TOKEN` | обязательная | да | токен @BotFather формата `<id>:<hash>`; уникален на инстанс | пользователь предоставляет, оператор вставляет |
| `OWNER_ID` | обязательная | нет | числовой Telegram ID владельца, `> 0` | пользователь предоставляет, оператор вставляет |
| `DATABASE_URL` | обязательная | нет | `sqlite+aiosqlite:////opt/corebot/app/data/corebot.db` | оператор |
| `LOG_LEVEL` | опциональная (дефолт `INFO`) | нет | `DEBUG`, `INFO`, `WARNING`, `ERROR` | оператор |

## Правила изменения

- Новую переменную добавляют одновременно в `.env.example` и в этот
  контракт (строка таблицы + допустимые значения + владелец).
- Переименование переменной требует примечания к релизу и переходного
  периода длиной не менее одного поддерживаемого окна (`N`, `N-1`,
  см. `RELEASE_CONTRACT.md`).
- Секреты (`да` в колонке «Секретно») никогда не коммитятся в Git,
  не выводятся в логи и не передаются в Ansible-инвентаре в открытом виде
  (только Ansible Vault или локальный vault, см. ADR 0001).
