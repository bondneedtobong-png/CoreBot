## Вердикт SQLite

Пороги ADR 0002 локально **НЕ превышены** ни по одному пункту:
WAL ~2 МиБ ≪ 256 МиБ, p95 записи ≤ 334 мс < 500 мс, busy 0 ≤ 5/мин,
exhausted 0, размер БД килобайты ≪ 5 ГБ, restore 0.01 с ≪ 30 мин,
писателей в тесте — десятки конкурентных сессий без деградации.
Отдельной PG-миграции **НЕ создавать** (п.8 задачи: только если превышены).
Условие «два замера ≥ 24 ч» для триггера тем более не выполнено.
