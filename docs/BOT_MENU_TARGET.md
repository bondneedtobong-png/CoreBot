## ComfyUI для фото аккаунтов

Локальная установка `C:/Users/bond/Documents/comfy/ComfyUI` доступна только на этой машине по `127.0.0.1:8188`; это не удалённый сервер и не подтверждение доступности с VPS. Бот запускает её по требованию. В меню ИИ есть создание вымышленного персонажа, генерация новых снимков по тексту и замена человека на загруженном фото-шаблоне с PNG-маской. Сходство лица и края маски нужно проверять вручную. Фото добавляется в набор рандомизации только после подтверждения; Telegram-профиль при генерации не меняется. Подробности — `COMFYUI_CHARACTERS.md`.
