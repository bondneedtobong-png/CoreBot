# Рабочий прототип: семь приоритетных сценариев

Срез: 2026-09-28. Запуск на Windows: `start_corebot.bat --check`, затем `start_corebot.bat`; панель — `http://127.0.0.1:8081/panel/`. Используются подключённые аккаунты и назначенные им SOCKS5-прокси. Лимиты GramGPT не считаются правилами Telegram.

| Сценарий | Где работать | Рабочий путь | Граница прототипа |
|---|---|---|---|
| Нейрокомментинг | Панель → Нейрокомментинг | Выбрать аккаунт и сообщение из своей группы либо вставить точную ссылку → проверить текст и права → создать/отредактировать AI-черновик → одобрить → увидеть статус отправки | Один ответ за раз; нет автоматического наблюдения за постами канала |
| ЛС-рассылка | Панель/бот → Рассылки | Создать кампанию и аудиторию с явным разрешением на контакт → preview → атомарно поставить неизменяемый снимок получателей → запуск/пауза/остановка → журнал | Нет многошагового конструктора; исходы, оставшиеся неопределёнными после сбоя, требуют ручной сверки |
| Нейрошиллинг | Панель → Нейрошиллинг | В своей группе найти недавнее сообщение другого участника → выбрать контекст → дать операторскую инструкцию о своём продукте → проверить/одобрить AI-черновик → ответить и проверить журнал | Это управляемые контекстные ответы; массовая автоматическая кампания, роли и искусственные рекомендации не реализованы |
| ИИ-защита аккаунта | Панель → Состояние аккаунтов | Общий постоянный gate останавливает отправки при явных ограничениях; здоровье и SOCKS5/auth проверяются отдельно; кнопка «ИИ-разбор» объясняет обезличенные наблюдаемые сигналы | ИИ-разбор консультативен и не снимает стоп, не проверяет Telegram и не предсказывает блокировку |
| Профили с рандомизацией | Бот → Аккаунты → Управление → Редактор профилей | Загрузить категории М/Ж/унисекс для имён, био, фото → выбрать аккаунт или группу → подтвердить → получить итог по аккаунтам | Нужны подготовленные данные в пулах; массовая правка каждого аккаунта проверяется отдельно |
| Прогрев | Бот → Прогрев | Настроить зону, рабочие часы и безопасный профиль → включить выбранные аккаунты → смотреть preview/отчёт. Действия выполняются вне рабочего окна, с интервалом не менее 30 минут; по умолчанию только чтение, реакции включаются отдельно | Прогрев не заменяет реальное поведение человека; нет многоэтапного календаря и отдельных лимитов для каждого действия |
| Парсинг | Панель → Парсинг | Preview входных источников/запросов → задача каналов, групп или пользователей → фильтры → результаты/причины исключений → TXT/CSV/XLSX | Семантический поиск и все расширенные фильтры отсутствуют; найденные пользователи автоматически не становятся ЛС-аудиторией |

Живые проверки 2026-09-27–28 на собственных аккаунтах и тестовой группе:

- Нейрокомментинг: admin-проверка точного сообщения, AI-черновик, одобрение и отправка через очередь бота; Telegram message ID 3.
- Нейрошиллинг: аккаунт №8 написал вопрос, поиск нашёл его, аккаунт №7 одобрил контекстный AI-ответ через работающий бот; Telegram message ID 5.
- ЛС-рассылка: тестовая кампания №4 зафиксировала ровно одного адресата (собственный аккаунт №8) и одного отправителя (№7); завершилась `COMPLETED`, результат 1 успешная отправка, 0 ошибок, Telegram message ID 252. Разрешение на контакт затем переведено в `opt_out`.
- Прогрев: вне рабочего окна профиль только с чтением диалогов выполнил одно действие `read_dialogs`, сохранил следующий срок; исходные настройки аккаунта восстановлены. Это подтверждает низкочастотный read-only путь, а не длительную многодневную работу.
- Парсинг: задача пользователей №3 прочитала собственную тестовую группу через работающий бот, завершилась с 2 результатами и 0 ошибок; найденные пользователи не добавлялись в ЛС-аудиторию.
- ИИ-защита: отдельный AI-разбор аккаунта №7 вернул объяснение локальных сигналов без изменения safety gate.

Редактор профилей и массовая рандомизация проверены локальными сценарными тестами; живую смену фото/имени/био для подключённых аккаунтов в этом прогоне не выполняли. На этой установке пока 0 шаблонов и 0 элементов в наборах имён, BIO и фото: перед рандомизацией их нужно загрузить через меню. Автоматическое длительное наблюдение, реальные массовые объёмы и восстановление после сетевого сбоя остаются отдельными проверками.

Перед рабочим запуском задайте реальные аудитории с разрешением на контакт, заполните пулы профилей и выберите аккаунты/группы прогрева. Пустые или отключённые настройки не запускают действия. За деталями всех 16 категорий см. `GRAMGPT_IMPLEMENTATION_MATRIX.md` и `GRAMGPT_SUBFEATURE_CHECKLIST.md`.
