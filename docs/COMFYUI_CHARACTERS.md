# Вымышленные персонажи через локальный ComfyUI

В боте: **ИИ → Вымышленные персонажи → Создать вымышленную внешность**. Опишите взрослого персонажа без имени реального человека. Бот запускает установленный на этом Windows-компьютере ComfyUI по требованию, создаёт опорный портрет и сохраняет его в `data/comfy_identities/<id>/`.

Выберите персонажа, опишите новую сцену и нажмите **Сцена по описанию**. Для следующих фото используется тот же опорный портрет и локальная модель PhotoMaker. Сходство лица нужно проверять по каждому результату: одна опорная фотография не даёт строгой гарантии идентичности. Фото попадает в набор рандомизации только после выбора категории М, Ж или − и отдельного подтверждения. Профиль Telegram при генерации не меняется.

**Фото-шаблон:** загрузите фото, на использование которого у вас есть право, затем PNG-маску того же размера. На маске белым выделите *всего человека*, которого нужно заменить, чёрным оставьте фон. Бот одинаково обрежет фото и маску до 1024×1024, слегка смягчит границу и создаст нового персонажа в выделенной области. Пустая маска отклоняется. Пока выделение делает пользователь: автоматический поиск человека на фото не предусмотрен. Просмотрите результат, в том числе края выделенной области, перед публикацией.

Локальная установка: `C:\Users\bond\Documents\comfy\ComfyUI`. Автозапуск доступен для `http://127.0.0.1:8188` на этом Windows-компьютере; на VPS нужна отдельная установка ComfyUI. Для сцен персонажа требуется официальный файл `photomaker-v1.bin` в `models/photomaker/`; на этой машине он установлен. Исходные фото-шаблоны временно хранятся в `data/comfy_templates/` и удаляются после генерации либо при следующем запуске шаблонного сценария через сутки. Сохранённые персонажи и утверждённые фото остаются локально в `data/`.
